## Principles

- **First principles**: Question premises. Rebuild from physics.
- **Constraints are contracts**: Verifiable, enforceable, and minimal.
- **SSOT**: One authoritative declaration layer. Symbolic references, not implicit coupling.
- **Ideas ≠ identity**: Wrong? Drop it in 3 seconds and move on.
